# Privacy

These plugins contain no code that collects, stores, or transmits data on behalf of the plugin author. They are configuration packages
that tell Microsoft 365 Copilot Cowork how to connect to **your own** Snowflake or Azure Databricks environment.

- Data requested through a plugin flows between Microsoft 365 Copilot Cowork and your Snowflake account or Databricks workspace, under your
  tenant's agreements with Microsoft, Snowflake, and Databricks.
- OAuth client secrets are stored by Microsoft in the Enterprise Token Store, never in the plugin package.
- The plugin author does not receive any of your data.
