# Copilot Cowork Data Platform Plugins

Two ready-to-build plugins for **Microsoft 365 Copilot Cowork** that connect Cowork to enterprise data platforms hosted on Azure, using each vendor's own
**managed MCP server**. There is nothing to host: Snowflake and Databricks run the MCP servers for you.

| Plugin | Connects Cowork to | MCP server used | Start here |
| --- | --- | --- | --- |
| [`snowflake-plugin`](./snowflake-plugin) | Snowflake (hosted on Azure) | Snowflake-managed MCP server (Cortex Agents, Cortex Analyst, Cortex Search, read-only SQL, custom tools) | [snowflake-plugin/README.md](./snowflake-plugin/README.md) |
| [`databricks-plugin`](./databricks-plugin) | Azure Databricks | Databricks-provided managed MCP servers: Genie One (default) and optionally Databricks SQL | [databricks-plugin/README.md](./databricks-plugin/README.md) |

Both plugins keep the platform's own security in charge: every request runs **as the signed-in user**, so Snowflake roles or Databricks Unity Catalog
permissions decide what each person can see.

## How installation works (both plugins)

1. A **platform administrator** (Snowflake or Databricks) creates the server-side access and an OAuth client. Neither vendor's MCP supports automatic
   client registration, so this manual step is required.
2. Someone registers that OAuth client in the **Microsoft Teams Developer Portal**, which stores the secret safely and returns a short **registration ID**.
3. The **build script** takes the server address and the registration ID, validates them, and produces a plugin ZIP. No secrets are ever written into the ZIP.
4. A **Microsoft 365 administrator** uploads the ZIP in the admin center.
5. Users turn the plugin on in Cowork, sign in once, and ask questions.

Each plugin README walks through these steps with checks after every step and a troubleshooting table.

## Requirements

- Microsoft 365 Copilot with Cowork, and an administrator who may upload custom apps.
- A Windows PC with PowerShell 5.1 or newer (built in on Windows 10/11) to run the build script. No other tools are needed.
- Admin access to Snowflake or Azure Databricks as described in each README.

## What is in each plugin ZIP

- `manifest.json`: generated by the build script from your values (Microsoft 365 app manifest v1.29, with an MCP **agent connector** using OAuth).
- `color.png` and `outline.png`: icons. Replace them in `package/` with your own branding before building if you want.
- `skills/<name>/SKILL.md`: a Cowork skill that teaches Cowork how to use the connector well (prefer governed tools, read-only, narrow queries, honest errors).
